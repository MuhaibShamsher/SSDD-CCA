# NED UNIVERSITY OF ENGINEERING & TECHNOLOGY

**Department of Computer Science & Information Technology**  
**CT-477 Secure Software Design & Development**

## SPRING 2026 - Complex Computing Activity

**Submission Deadline:** May 17th, 2026

Build any software system of your choice that demonstrates secure software design and development principles. Your project must include at least three security vulnerabilities that you intentionally place in your code. Then you must fix each one and prove your fix works.

## Requirements

1. A working software application (web, mobile, API, desktop, any platform)
2. At least three distinct security vulnerabilities intentionally added
3. Vulnerable version (code with vulnerabilities)
4. Fixed version (code with all vulnerabilities eliminated)
5. Automated tests that fail on vulnerable version and pass on fixed version
6. Demo video showing each attack and fix (max 4 to 5 minutes video)

## Deliverables

1. **Github Repository Link:** Code with vulnerable and fixed versions + README
2. **Tests Scripts:** Automated tests (one per vulnerability) in repository
3. **Demo Video:** Max 4 minutes showing each attack and fix (YouTube/Drive link)
